# 🖊️ Interactive Whiteboard Pro

> سبورة تفاعلية احترافية للمدرّس العربي — رسم فيكتور، معادلات LaTeX، شرح فوق PDF، تصدير للـWord، أوراق عمل آلية موثقة الدقة.

---

## 🎯 الرؤية

تحويل أي جهاز Windows إلى استوديو شرح متكامل: لوحة رسم GPU سلسة، أدوات هندسية واقعية، مكتبات علمية جاهزة، ومولّد أوراق عمل يضمن دقة الرياضيات رياضياً — بواجهة عربية أولاً.

---

## ✨ الإمكانيات الكاملة

### 1) الرسم والكتابة
| الميزة | التفاصيل |
|---|---|
| أنماط أقلام فورية | **Fine** رفيع · **Brush** حبر متغير العرض يشعر بسرعة اليد · **Marker** تظليل شفاف |
| أدوات الأشكال | خط · سهم · مستطيل · بيضوي · نص (نقرة مزدوجة) |
| تحكم كامل | لون + سمك من لوحة الخصائص الحية (تعمل على المفرد والمجموعات) |
| 🔴 Laser Pointer | خيط أحمر يتلاشى خلال 1.5 ثانية — للإشارة أثناء الشرح الحي |
| 🌙 Chalkboard | تحويل اللوحة لسبورة طباشير داكنة بضغطة |

### 2) الأدوات الهندسية الواقعية (بظلال حقيقية)
| الأداة | الوظيفة |
|---|---|
| 📏 Ruler | مسطرة شفافة بمقياس سم/مم — الرسم على حرفها = خط مستقيم مثالي |
| 📐 Protractor | منقلة 0-180° بتدريجات كل 5° — أقواس بزوايا مضبوطة |
| 🧭 Compass | فرجار حي: أرجح الرِجل → قوس يتشكل مع عرض `R=` لحظياً |

جميعها قابلة للسحب والدوران من مقابضها، وحجمها ثابت مهما تغيّر الزوم.

### 3) معادلات LaTeX — فيكتور نقي
- أداة **ƒx LaTeX**: اكتب `\frac{b^2-4ac}{2a}` مع **معاينة حية**
- الناتج **مسارات Bézier حقيقية** (ليست صورة): تكبير لا نهائي، تلوين وتحجيم من لوحة الخصائص
- يُصدَّر SVG/PDF كمسارات فيكتور خالصة

### 4) مستندات PDF — دورة كاملة
```
📄 In (اختيار الدقة 96-400ppi)
  ├─ One app-page each → كل صفحة PDF = صفحة سبورة
  └─ Current page → في وسط السبورة
🔒 Unlock → تفكيك الصفحة لكائنات فيكتور حرة
   (كل نص يصبح نصاً، كل خط مساراً — قابل للتعديل)
Ctrl+E Flatten Export:
  ├─ ☑ Keep original pages vector → PDF الأصل يبقى فيكتوراً
  │   والشرح يُضاف كطبقة فوقه (show_pdf_page + overlay)
  ├─ توازن Raster⟷Vector + دقة حتى 1200ppi
  └─ Copy for Word → بالدقة المختارة
```

### 5) تكامل Word — حافظة ذكية
`Ctrl+C` يضع **4 صيغ معاً**:
- **SVG فيكتور** (Word 2016+ يلصقها كرسم متجهي)
- PNG شفاف + DIB بأرضية بيضاء (توافق كل الإصدارات)
- كائنات داخلية (اللصق في السبورة يبقى قابلاً للتعديل)

والعكس: انسخ صورة من Word → `Ctrl+V` في السبورة → تُدرج كائناً قابلاً للشرح.

### 6) مولّد أوراق العمل الذكي 📝
- **19 موضوعاً**: رياضيات (12) + كيمياء (7) بمستويات صعوبة 1-5
- **ثلاث طبقات ضمان دقة**:
  1. فحص ذاتي لكل مسألة (تعويض الجذور، محدد ≠ 0، F'=f...)
  2. منع التكرار داخل الورقة
  3. بذرة Seed قابلة للإعادة (`ws#12345` مطبوع في التذييل)
- تصدير **PDF احترافي RTL**: ترويسة، أسطر إجابة، **صفحة تصحيح منفصلة**

### 7) مكتبات علمية جاهزة
| المكتبة | المحتوى |
|---|---|
| ⚗️ Chemistry | 28 معادلة موزونة بـ6 فئات |
| ⚡ Physics | 35 معادلة في 7 فئات (Kinematics → Thermo) |
| 🧭 Periodic Table | أول 36 عنصراً |

### 8) التنظيم
- **صفحات** متعددة (◀ ▶ ＋ ✕)
- **طبقات** Layer بإظهار/إخفاء وتوسيم تلقائي للرسم الجديد
- **تحديد/نقل/حذف** + **Group/Ungroup** (Ctrl+G / Ctrl+Shift+G) — التجميع يُحفظ بالملف وينسخ كوحدة
- Undo/Redo (60 خطوة)

### 9) التصدير
| الصيغة | المسار |
|---|---|
| `.wbd` مستند | كل الكائنات + الطبقات + الصفحات — قابل للتعديل لاحقاً |
| PNG | حتى 1200ppi، شفافية اختيارية، تحديد فقط أو الكل |
| PDF فيكتور | نص حقيقي قابل للتحديد + مسارات (صفر صور) |
| SVG | فيكتور للويب والتصميم |
| Word | مباشرة من الحافظة |

## 🛠️ البنية التقنية

| الطبقة | التقنية |
|---|---|
| الواجهة والرسم | **PySide6 (Qt6)** — QGraphicsScene/View، عرض متسارع |
| المعادلات | matplotlib mathtext → QPainterPath فيكتور |
| PDF | PyMuPDF (استيراد/overlay فيكتور) + QPdfWriter + reportlab (أوراق العمل RTL) |
| المنطق العلمي | SymPy رمزياً |
| العربية | arabic_reshaper + python-bidi |
| الحزمة | ملف واحد `whiteboard_qt.py` (~2600 سطر) + `instruments` موروثة |

## 🚀 التشغيل والبناء

```bash
pip install -r requirements.txt
python whiteboard_qt.py            # تشغيل مباشر

# بناء exe
pyinstaller --onefile --windowed --name WhiteboardPro --icon icon.ico \
  --collect-data matplotlib --collect-data arabic_reshaper whiteboard_qt.py
```
